# Privacy Policy

ChargeFreeze is designed to work entirely on-device.

- It does not request the Android `INTERNET` permission.
- It does not collect, transmit, sell, share, or monetize personal data.
- It contains no analytics, advertising, crash-reporting, tracking, account, or cloud SDK.
- Battery state, device manufacturer information, and battery-protection settings are read only for local operation and diagnostics.
- Recovery state is stored locally in app-private preferences so original battery-protection values can be restored.

Uninstalling the app removes its local app data. Because Android cannot run app code after uninstall, stop an active freeze session and restore settings before uninstalling.
